连接你的博客

使用 GitHub 访问令牌连接，仅限博客所有者 fen-dada。

  1. 打开 GitHub 创建访问令牌 ↗。
  2. 在 Repository access 中选择 Only select repositories，只勾选 fen-dada.github.io。
  3. 确认 Contents 权限为 Read and write，点击 Generate token，复制结果到下方。

只发送给 GitHub，仅保留在当前页面内存中。刷新页面后需要重新连接，请妥善保管令牌，不要把它写进作品。
